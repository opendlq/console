# OpenDLQ UI

Design system em **Angular 22** (standalone, zoneless, signals, `OnPush`) para construir um console de **Dead Letter Queues** no estilo do Conduktor Console. CSS puro + _design tokens_, sem Tailwind nem Material.

## Como usar

```ts
import { OdlqButton, OdlqMessageTable, OdlqThemeService } from '@opendlq/ui';
```

Importe os estilos globais uma vez (`angular.json` → `styles`):

```json
"packages/ui/src/styles/index.css",
"node_modules/@angular/cdk/overlay-prebuilt.css"
```

O tema vive em `<html data-theme="light|dark">`. Use `OdlqThemeService` ou o seletor **Tema** na barra do Storybook.

## Convenções

- Seletor `odlq-*`, classes `Odlq*`, um arquivo por componente, template e estilos inline.
- Entradas com `input()`, saídas com `output()`, estado bidirecional com `model()` (`[(value)]`, `[(open)]`).
- Controles de formulário implementam `ControlValueAccessor` e funcionam com `ngModel` e Reactive Forms.
- Dados de exemplo em `mocks.ts`, compartilhados por stories e pelo app.
- Tetos conhecidos estão marcados com comentários `ponytail:` (ex.: editor de código por `textarea`, diff O(n·m)).
